# Scene authoring guide

This project renders a vertical (1080×1920, 30 fps) Chinese explainer video with Remotion.
Voice, captions, the chapter bar, background and music are **global layers** in `src/Main.tsx`.
A scene component only draws the **stage** (the animated infographic) for its time slot.

## Files

- `src/data/script.json`: the storyboard (scenes → lines, with `visual` / `visual_cue` directions).
- `src/data/timeline.json`: generated by `scripts/build_tts.py`. It holds frame timings for every scene and line.
- `src/scenes/<sceneId>.tsx`: **one file per scene, default export**, no props.
- `src/scenes/index.ts`: registry (generated). Do not edit it while scenes are built in parallel.

## Coordinates and layout

```
y   0 ─ 110   empty (phone status bar / platform UI)
y 120 ─ 212   ChapterBar (global, only during 第1–4步)
y 250 ─ 1290  STAGE: put the scene's visuals here (1040 px high)
y 1330 ─ 1600 Captions + speaking mascot (global). Draw nothing important below y≈1300
y 1600 ─ 1920 platform UI overlays (title/hashtags). Keep empty
x: keep text within 60 … 1020
```

For scenes with no chapter bar (开场, 结尾), the stage may start at y≈140.

Position absolutely inside `<AbsoluteFill>`, or use `ZONE.stageTop` / `ZONE.stageBottom` from `src/theme.ts`.

## Timing API (`src/timeline.ts`)

Inside a scene, `useCurrentFrame()` is **relative to the scene start**.

```tsx
const { at, endAt, n, scene } = useLineStarts();
at(0)      // frame where line 0 starts being spoken; at(-1) = last line
endAt(2)   // frame where line 2 ends
scene.duration
const wordAt = useWordTime();
wordAt(1, "5.3")   // approx. frame where "5.3" is spoken in line 1 (use for precise beats)
```

Sync every visual beat to the line or word that mentions it. Make an element appear ~3–6 frames **before** its word
(`at(i) - 4`) so it lands with the voice. Scenes last exactly as long as their lines (plus ~0.3 s lead-in and tail).

## Design system (`src/theme.ts`, `src/components/kit.tsx`)

- Style: bright "neo-brutalist sticker" look. Cream background (global), white cards with a **6 px ink border**,
  radius 24–36, **hard offset shadow** `10px 10px 0 #1B1B1F`. Use `<Card>`.
- Colors: `C.ink #1B1B1F`, `C.blue #4285F4`, `C.red #EA4335`, `C.yellow #FBBC05`, `C.green #34A853`, plus soft
  variants (`C.blueSoft`…). Semantics: green = good/ok, red = warning/waste, yellow = highlight, blue = data/neutral.
  Chapter colors (`CHAPTER_COLOR`): 开场 red, 第1步 blue, 第2步 orange (`C.orange`), 第3步 purple (`C.purple`), 第4步 green, 结尾 gold (`C.gold`).
- Fonts (`FONT`): `display` (ZCOOL QingKe HuangYou) for big headlines, `black`/`bold`/`medium` (Noto Sans SC) for text,
  `num` (Montserrat Black) for numbers. Sizes: headline 80–120, body 44–60, **minimum 34**. Chinese needs room: ~1 em per char.
- Emoji via `<Emoji e="💰" size={120}/>` (Noto Color Emoji).
- Kit: `Pop` (spring entrance: scale/up/down/left/right/fade, optional `out` frame), `Card`, `Title`, `Txt`, `Marker`
  (highlighter sweep), `Stamp` (slammed rubber stamp), `Counter` (animated number), `DrawArrow` (SVG path draw-on),
  `Sfx`, `useSpring`, `useProgress`, `useFloat` (idle bob), `useShake`, `clamp`.
- Mascots (`src/components/Mascots.tsx`): `<MascotFace kind="cat"|"dog" size={260} talking={0..1} mood="normal|happy|shock|smug|sad"/>`.
  The **cat with glasses is the expert**. The **puppy is the eager seller**. For a big in-scene mascot that lip-syncs,
  pass `talking={talkingAt(idOfKind("cat"), scene.start + frame)}`. The caption bar already shows the speaking mascot
  small, so in-scene mascots are optional. Use them for reactions: shock, smug, sad.
- Recurring prop: a big glossy red **「加预算」 button**. Draw it with divs/SVG (red dome, dark base, white label).
  Keep it the same look in every scene that uses it: `src/components/BudgetButton.tsx` if present.

## Motion rules

- Something must move at all times. No static stage for more than ~1.5 s. Use `useFloat` idle bobbing, pulsing
  highlights, counters, drawing lines.
- Entrances use springs (`Pop`). Stagger lists by 4–8 frames or by line timing. Avoid slow fades; this is a snappy
  short video.
- Emphasis: `Stamp`, `useShake`, scale punch (1 → 1.12 → 1), `Marker` under key words.
- Transitions: `SceneShell` in `Main.tsx` already does a quick fade/slide in and out for every scene. Do not add
  whole-scene fades yourself.

## Sound effects

Line-level SFX from `script.json` (`sfx` field) are played automatically at the line start. Add extra
`<Sfx name="pop" at={frame} volume={0.35}/>` only for additional beats inside a line (items popping in, stamps,
counters finishing). Available sounds (`public/sfx/`): whoosh, swish, riser, pop, click, ding, chime, cash, coin,
buzzer, stamp, boing, sparkle, typing, scratch, ticktock, drumroll, impact, sadtrombone, fanfare.
Volume 0.2–0.5. Space them out; at most about one SFX per second.

## Content rules

- **Never show facts or numbers that are not in the script/source.** Illustrative bars and lines without numeric labels
  are fine. Do not label an illustrative bar with a made-up value.
- No real Google logo or screenshots. A simplified mock ad dashboard panel (cards, table rows, text "Google Ads") is fine.
- On-screen text should reinforce, not duplicate, the caption: keywords, numbers, formulas, short labels.
- All on-screen Chinese must be Simplified Chinese.

## Checking your scene

```bash
npx tsc --noEmit -p . 2>&1 | grep "scenes/<sceneId>"   # only your file; other scenes may be mid-edit
node scripts/stills.mjs <sceneId> auto                  # renders stills at every line start (isolated bundle)
node scripts/stills.mjs <sceneId> 10,40,80,120          # or chosen relative frames
```

Then view `out/stills/<sceneId>_sheet.jpg`, or the individual PNGs in `out/stills/<sceneId>/`, with the image
viewer (Read tool). Check for: overlapping or clipped text, elements outside the stage, anything under the caption
zone, unreadable sizes, empty/static frames, and elements that appear too late for their line.
